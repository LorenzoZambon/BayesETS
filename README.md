**BayesETS** implements Bayesian ETS (exponential smoothing) state-space
models, which account for both parameter and model uncertainty.
Currently, only additive models are supported. Initial states and the
observation variance are analytically marginalized via conjugate
Normal-Inverse-Chi-Squared priors. The smoothing parameters
($\alpha, \beta, \gamma, \phi$) are either integrated by adaptive
Gauss-Hermite quadrature (AGHQ) or sampled via Adaptive Importance
Sampling (AIS). Multiple ETS models are combined by Bayesian Model
Averaging (BMA). Forecasts are generated by `predict()` as sample-path
trajectories.

Key features:

- **Parameter uncertainty**: parameters are integrated over their
  posterior distribution, rather than estimated as point values.
- **Model uncertainty**: the additive ETS models are combined via BMA,
  rather than selecting a single one.
- **Fast**: analytical marginalization reduces the dimension of the
  integration space to (at most) 4; likelihood evaluation is vectorized
  and implemented in C++. Running on 1 core of a laptop with an AMD
  Ryzen 5, on the M3 data `bets()` requires on average 0.12 s per
  monthly series, 0.07 s per quarterly and 0.02 s per yearly one (median
  length: 115, 44 and 19 observations respectively).

## Installation

You can install the development version from
[GitHub](https://github.com/LorenzoZambon/BETS):

``` r
# install.packages("remotes")
remotes::install_github("LorenzoZambon/BETS")
```

The package contains C++ code: installing it from GitHub requires a
compiler (Rtools on Windows, the Xcode command line tools on macOS, a
C++ compiler on Linux).

## Example: M3 monthly series

We fit `bets()` and `ets()` (from the forecast package) to a monthly
series of the M3 competition, and compare their forecasts with the
observed test set.

`ets()` estimates the parameters of each model via maximum likelihood
and selects a single model by AICc. `bets()` fits all the additive
models and averages them, with weights given by their posterior
probabilities; within each model, it integrates over the posterior of
the parameters.

``` r
library(BayesETS)
library(forecast)   # for comparison with ets()
library(Mcomp)      # M3 competition data
library(ggplot2)    # for plot

set.seed(123)
```

``` r
series  <- M3[["N2471"]]
y_train <- series$x
y_test  <- series$xx
h       <- length(y_test)

bets_fit <- bets(y_train, additive.only = TRUE)
ets_fit  <- ets(y_train, additive.only = TRUE)
```

weight to each one:

**Parameters.** For the model selected by `ets()`, we compare its
maximum likelihood estimates with the posterior of the same model in
`bets()` (mean, standard deviation and 95% credible interval, from
`summary()`):

``` r

post  <- summary(bets_fit)$parameters[[model]]
ml    <- c(ets_fit$par[setdiff(rownames(post), "sigma")], sigma = sqrt(ets_fit$sigma2))
round(cbind(ets = ml, post), 3)
```
