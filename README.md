**BETS** implements a fully Bayesian ETS state-space model, which
accounts for both parameter and model uncertainty. Currently, only
additive error models are supported. Initial states and the observation
variance are analytically marginalized via conjugate
Normal-Inverse-Chi-Squared priors; only the smoothing parameters (α, β,
γ, φ) are sampled via Adapive Importance Sampling (AIS). Multiple ETS
variants are combined by Bayesian Model Averaging (BMA, default) or
stacking. Forecasts are generated by `predict()` as sample-path
trajectories.

Key features:

- **Parameter uncertainty**: parameters are sampled from the posterior
  distribution.
- **Model uncertainty**: model combination is implemented via BMA
  (default) or stacking over the additive-error ETS model family.
- **Fast**: Rao-Blackwellization reduces the dimension of the sampling
  space; likelihood evaluation is vectorized and implemented in C++.

## Example: M3 monthly series

First, load the packages and set the seed.

``` r
library(BETS)
library(forecast)   # for ets() comparison
library(Mcomp)      # M3 competition data
library(ggplot2)    # for plotting

set.seed(123)
```

We now fit BETS and ETS (from the forecast package) to a series from the
M3 dataset. ETS uses a maximum likelihood point estimate of the
parameters, while BETS accounts for uncertainty over these parameters by
drawing samples from the posterior distribution. Moreover, `ets()`
selects a single model by AICc, BETS instead automatically combines
multiple ETS variants.

``` r
# Pick a time series from the M3 dataset
freq_series <- "MONTHLY"  # either "MONTHLY", "QUARTERLY", or "YEARLY"
j <- 10  # index of series to fit and plot 
series <- Filter(function(s) s$period == freq_series, M3)[[j]]
y_train <- series$x                 
y_test  <- series$xx               
h       <- length(y_test)

# Fit models 
bets_fit <- BETS::bets(y_train)                               
ets_fit  <- forecast::ets(y_train, additive.only = TRUE) 

# Print details on the fitted models
print(ets_fit)    # print ETS model selected by AIC
#> ETS(A,N,N) 
#> 
#> Call:
#> forecast::ets(y = y_train, additive.only = TRUE)
#> 
#>   Smoothing parameters:
#>     alpha = 1e-04 
#> 
#>   Initial states:
#>     l = 4609.746 
#> 
#>   sigma:  1504.858
#> 
#>      AIC     AICc      BIC 
#> 931.2054 931.7272 936.9415
print(bets_fit)   # print model weights
#> BETS model fit
#>   length of the series: 50
#>   frequency: 12
#> 
#>   Models and weights:
#>   ANN   weight: 0.028
#>   AAN   weight: 0.000
#>   AAdN  weight: 0.000
#>   ANA   weight: 0.920
#>   AAA   weight: 0.012
#>   AAdA  weight: 0.039
```

We then compute forecasts from both models.

``` r
# Compute forecasts
bets_fc <- predict(bets_fit, h = h, level = c(80, 95))
ets_fc  <- forecast(ets_fit, h = h, level = c(80, 95))
```
